# 演示界面规范

产物是**纯静态 HTML**：无构建、无外链 CDN、无 npm 依赖。双击能开，手机能看。

## 工作台（console/index.html）

```
┌──────────┬────────────────────────────────┐
│ 品牌      │ 顶部：模块名 · 面包屑 · 搜索 · 主操作 │
│ 侧边栏    ├────────────────────────────────┤
│ 模块列表  │ KPI 卡 × 4                       │
│          │ 表格：字段列 + 操作列              │
│ 底部说明  │ 空状态引导                        │
└──────────┴────────────────────────────────┘
```

约定：
- 侧边栏按**使用频率**排，最常用的在第一个（不要按"重要程度"排）
- KPI 卡 4 个，第一个是当天最关心的那个数
- 表格 7 行演示数据，能搜索、能新增一行（前端克隆）
- 操作列只留**一个**主动作，其余收进详情

## 移动端（h5/index.html）

```
┌────────────────────┐
│ 顶部色块：项目名 + 角色 │
│ KPI 条（3 个，浮在色块上）│
│ 功能宫格 2 列         │
│ 最近动态列表          │
│ 主 CTA 按钮          │
│ 底部 tabbar 4 项      │
└────────────────────┘
```
- 宽度 430，桌面居中显示
- 点宫格 → 底部抽屉表单（预填演示值），提交即关闭
- 一屏能看懂"这是什么店、谁在用、干什么"

## 设计令牌

在 `templates/app.css` 中统一维护：

| 变量 | 用途 |
|---|---|
| `--accent` | 行业主色，由行业数据注入 |
| `--bg / --panel` | 页面底色 / 卡片底色 |
| `--ink / --ink-2 / --ink-3` | 正文 / 次要 / 弱化 |
| `--line` | 边框 |
| `--radius` | 圆角（12px） |

行业主色按语义选：餐饮暖色（橙红）、医疗青绿、金融深蓝、教育蓝紫、律所藏青。**不要所有行业都用同一个蓝**。

## 演示数据规则

数据由 `lib/core.mjs` 的 `valueFor()` 按**字段名语义**生成，规则：

- 金额 → `¥` + 千分位
- 比率 → 一位小数（`2.2`）或百分比（`76%`）
- 日期 → `YYYY-MM-DD`，围绕今天前后偏移
- 状态 → 进行中 / 已完成 / 待处理 / 已取消（自动配色标）
- 手机号 → `13x…`；车牌 → `京A12345`；桌号 → `A08`
- 人数 → 2~8（不要 51 这种）

**禁止**出现"示例 / 默认 / 常规 / 待定"。出现即视为生成器没覆盖到该字段，应该去 `valueFor()` 补规则。

## 接后端时要改哪里

- 工作台：`<tbody data-body>` 换成接口渲染；搜索改成服务端查询
- H5：宫格数据来源 `v.modules` 换成接口；抽屉提交改 POST
- 页面顶部那句"演示用静态数据"在接完接口后删掉

## 自检

- [ ] 1440×900 下工作台不横向滚动
- [ ] 430 宽下 H5 不横向溢出（长文案在两列格子里会撑破 `1fr`，需要 `min-width:0`）
- [ ] 每张表的列数 ≤ 5，列名是行业词
- [ ] 每个状态都有颜色，不是纯文字
